## Numbered Findings (Prioritized)

1. **[HIGH] [R-09] Capsule Badge Parked Directly Above H1:**
   `docs/index.html` places `<span class="badge mono">WINDOWS 10/11 X64 · ZERO CLOUD DEPENDENCY</span>` directly above `<h1>A living desktop island built for builders.</h1>`. Replace with plain kicker line or merge hardware platform detail cleanly inside the lead subtitle so the H1 stands uncluttered.
2. **[HIGH] [R-12 / R-14] Uniform Hard Elevation Across Every Surface:**
   In Paper theme, `.topbar`, both `.hero .card` blocks, both `.video-card` panels, feature cards, skin browser, and shortcut table all carry `4px 4px 0 #2D2D2D` shadow + `2px` border, flattening hierarchy. Reserve the NeoBrutalist offset shadow for the hero primary focal card + live interactive Island simulator; keep secondary documentation cards, feature grid, and table flat (`box-shadow: none`).
3. **[HIGH] [R-40 / R-27] `<video>` Intrinsic Height Stretching & Black First-Paint Box (`docs/showcase_proof_1440.png`):**
   Setting HTML `width="1920" height="1080"` without `height: auto; aspect-ratio: 16 / 9;` caused oversized vertical black letterbox blocks inside `.video-card video`, compounded by reusing wide proof sprite sheet `all_skins_transitions_proof.png` as poster. Enforce `aspect-ratio: 16 / 9; width: 100%; height: auto;` and assign dedicated 1080p keyframe posters (`assets/reel1_poster.png`, `assets/reel2_poster.png`).
4. **[MEDIUM] [R-26 / R-09] Decorative Non-Interactive Simulator Chips:**
   `SMTC Media Ready`, `Ctrl+Alt+T Timers`, and `Ctrl+Alt+S Swarm` below `#simBar` looked like interactive toggles/pills but did nothing on click. Convert them into working `<button>` simulator view switchers (`CPU`, `Pomodoro`, `SMTC`, `Swarm`) that update the live island preview bar and active mascot state (`C-2`).
5. **[MEDIUM] [R-03] Missing Explicit Intermediate Tablet Breakpoint & Mobile Lazy-Scroll Proof:**
   Layout jumped between `>860px` desktop 2-col and `<=480px` mobile without an intermediate tablet (`<=960px`) rule for hero + video cards (`antislop-layoutmobile` 3-state rhythm). Also add automated scroll pass in Playwright (`audit_showcase.py`) across `1440`, `1024`, `768`, and `375` viewports to decode all 48 below-the-fold lazy skins (`brokenImgs=0`), test empty search reset, and verify keyboard Tab focus (`R-32`).
6. **[LOW] [R-15 / R-16 / C-5] Generic Copy Polish & Multilingual Alignment:**
   Removed remaining generic promo wording ("Showcase Beats" -> "Collection Beats") across English strings and ensured interactive installer / doc links map cleanly without fabricated metrics.
